# Workout Generator

A small website that generates a short home workout based on my available time, focus,
equipment and level. Every click gives a different combination of exercises. A history
shows how many minutes I trained this week compared to my weekly goal.
Built with plain HTML, CSS and JavaScript, step by step with GitHub Copilot.

## How to open
Open `index.html` in a browser (double-click the file or use the Live Server extension
in VS Code). No installation needed.

## Features
- Choose duration, focus, equipment and level in a form
- Summary line, e.g. "20 min | full body | medium"
- 4 random exercises that match my choices, with warm-up, cool-down and rounds
- "New workout" shuffles the exercises
- "Done!" saves the workout in a history table (still there after a reload)
- Progress bar: minutes trained this week vs. goal of 60 min

## Project files
- `SPEC.md` – what to build (and what not)
- `AGENTS.md` – rules for Copilot
- `PROGRESS.md` – steps done and decisions
